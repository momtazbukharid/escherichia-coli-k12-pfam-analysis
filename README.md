# Pfam analysis of *Escherichia coli* K-12

This repository contains scripts, input files, and selected results from Pfam and conserved-domain analyses of the *Escherichia coli* K-12 proteome.

## Analyses

- Complete Pfam-A domain analysis
- Essential 102 Pfam analysis
- FastAAI 122 Pfam analysis
- Persistent 500 Pfam analysis
- Hypothetical-protein analysis
- Domain of unknown function (DUF) analysis
